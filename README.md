## 🌟 Overview
**Second Brain** is a full-stack personal knowledge management application. It helps users organize important content across the internet into one unified dashboard and share custom link collections with others.

### ✨ Features
- 🔐 **User Authentication:** Secure JWT-based Sign Up and Sign In system.
- 📌 **Content Bookmarking:** Save YouTube videos, Twitter / X posts, articles, links, and quick notes.
- 🗂️ **Categorized Dashboard:** Filter and browse your stored memories with clean UI tags and icons.
- 🔗 **Share Your Brain:** Generate a unique, shareable public link with an encrypted hash so others can explore your curated brain.
- 🗑️ **Management:** Quick deletion and management of saved entries.

---

## 🛠️ Tech Stack
- **Backend:** Node.js, Express 5, TypeScript, MongoDB & Mongoose, JSON Web Tokens (JWT), Dotenv, CORS
- **Frontend:** HTML5, Modern Vanilla JavaScript (SPA), Tailwind CSS, FontAwesome Icons

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/aribanaz11/second-brain-App.git
cd second-brain-App
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup Environment Variables
Create a `.env` file in the root directory (refer to `.env.example`):
```env
PORT=3005
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### 4. Run the application
```bash
npm start
```
The server will launch at `http://localhost:3005`!
